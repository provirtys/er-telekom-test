# Тестовое задание для ЭР-Телеком

**Описание проекта**  
Приложение позволяет просматривать и управлять различными объектами телекоммуникационной организации, такими как: города, районы, улицы, дома и подъезды. У каждого типа объекта присутствует свой тип полей, а также своё оборудование, которое за ними закреплено. Для доступа к функционалу необходимо войти в систему (доступна регистрация нового пользователя).  

В интерфейсе предусмотрены горячие клавиши:  
- **Enter** — отправка формы  
- **Esc** — закрытие модальных окон/форм  

Приложение обладает простым дизайном, поддерживает адаптивную верстку для мобильных устройств и документировано с использованием JSDoc. Все компоненты интерфейса разработаны вручную с нуля.

## 🚀 Функциональность

- Управление объектами телекоммуникационной организации:
  - **Города**
  - **Районы**
  - **Улицы**
  - **Дома**
  - **Подъезды**
- Поддержка различных типов полей для каждого объекта
- Привязка оборудования к объектам
- Аутентификация и регистрация пользователей
- Горячие клавиши для удобства работы с формами и модальными окнами
- Адаптивный дизайн для мобильных устройств
- Документирование компонентов и функций с помощью JSDoc

## 🛠️ Технологии

- [Vue 3](https://vuejs.org/) — фронтенд-фреймворк для построения пользовательских интерфейсов  
- [Pinia](https://pinia.vuejs.org/) — управление состоянием приложения  
- [Firebase](https://firebase.google.com/) — бекенд как сервис для аутентификации и хранения данных  

### Требования для запуска в локальной среде
- Node.js 18.20.0 версии или выше

### Установка зависимостей
```npm install```
### Запуск локального сервера
```npm run dev```
### Запуск билда 
```npm run build```
